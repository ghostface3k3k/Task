# HR Management System

## Overview
The HR Management System is a monorepo designed to streamline various human resource operations and functionalities. This system includes modules for:

- **Employee Management**: Onboarding, offboarding, and employee records management.
- **Leave Management**: Requesting, approving, and tracking employee leave.
- **Payroll Management**: Calculation, distribution, and record-keeping of employee salaries and benefits.
- **Performance Management**: Tools for employee evaluations, feedback, and goal setting.
- **Recruitment**: Managing job postings, applicant tracking, and interview processes.

## Goals
The primary goals of the HR Management System are to enhance productivity, minimize manual errors, and ensure compliance with labor laws through automated systems.

## Technologies Used
- **Frontend**: React, Redux
- **Backend**: Node.js, Express
- **Database**: MongoDB

## Getting Started
To get started with the HR Management System, clone the repository and run the following commands:

```bash
npm install
npm start
```
